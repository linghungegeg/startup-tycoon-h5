# 跨服主页美工出图规范

## 目标

跨服主页继续使用 `941x1672` 固定画布。`kuafugai.png` / `cross-server-main.png` 作为正式无 UI 底图，前端只在 Canvas 中叠加可替换头像、员工人物和热数据文字。

本规范的目的不是让美工重做整张背景，而是补齐干净动态素材层，避免前端继续裁旧图、遮旧字、叠双框。

## 现有底图

- 正式底图：`apps/client/public/game-ui/cross-server/cross-server-main.png`
- 调试参考：`apps/client/public/game-ui/cross-server/kuafu.png`
- 尺寸固定：`941x1672`
- 保留标题、背景、按钮、头像空圆框、员工卡空框。
- 不恢复左侧 `1/2/3/4` 徽章。

## 需要交付的干净素材

| 类型 | 接入方式 | 建议尺寸 | 要求 |
| --- | --- | --- | --- |
| 对手头像 | 通过 API 的 `arena.opponents[].avatarUrl` 进入 Canvas | `132x132` 或 `264x264` | 我方透明 PNG，只保留人物头像；不带圆框、徽章、外发光、背景边框。 |
| 员工人物 | 通过 API 的 `arena.lineup[].portraitUrl` 或员工配置 `portraitUrl` 进入 Canvas | `160x213` 或 `320x426` | 我方透明 PNG，只保留人物主体；不带岗位标签、`Lv.60`、卡框、底部遮罩。 |
| 坐标标注 | PSD、Figma 或标注 PNG | `941x1672` | 在原始画布上标出头像框、员工卡框、文字基线位置。 |

所有坐标必须基于 `941x1672` 原始画布，不使用浏览器缩放后的截图坐标。

## 前端接入规则

- 继续绘制 `cross-server-main.png` 作为 Canvas 底图。
- 头像和员工人物通过 API URL 进入 Canvas，不按固定 4 张对手或固定 5 张员工定义最终交付。
- URL 为空或加载失败时回退到当前旧素材，保证开发环境不空白。
- Canvas 只绘制干净头像、干净员工人物和动态名称、战力、排名、等级、岗位标签。
- DOM 只保留透明热区，不恢复可见文字层和可见图片层。
- 不加载、不绘制 `opponent-medal-*`，左侧 `1/2/3/4` 徽章差异在本轮验收中忽略。

## 验收标准

- 正常页无双框、无旧岗位标签、无旧 `Lv.60`。
- debug 叠层只检查头像框、员工框、按钮、文字位置。
- 动态数据变化时，头像和员工人物仍落在同一套坐标内，不依赖静态截图写死。
- 如果没有干净人物层，前端只能继续回退旧素材；这会保留裁切和遮盖成本，不作为最终视觉验收状态。
